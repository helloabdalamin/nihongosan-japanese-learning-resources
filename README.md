# NihongoSan Japanese Learning Resources

A small, beginner-friendly Japanese learning resource for Bengali-speaking learners.

## What's included

- `vocabulary-n5.csv`: starter Japanese vocabulary with kana, romaji, and Bengali meanings
- `index.html`: a simple browser-based vocabulary flashcard quiz
- `LICENSE`: MIT License

## How to use

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click **Show answer** to reveal the Bengali meaning.
4. Use **Next** to move to another word.

## Learning note

This is a small starter resource, not a complete JLPT N5 vocabulary list. Please review and improve the entries as the project grows.
